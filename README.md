# Sky-Rock

Sky-Rock is a safe aerial robotics research platform for:

- UAV and object detection
- dataset conversion and merging
- computer vision inference
- dashboard monitoring
- blockchain-based audit logging
- Docker/Kubernetes deployment
- simulation and decision-support research

## Scope

This project is for civilian, academic, and research use only.

The system focuses on:

- detection
- tracking
- monitoring
- logging
- visualization
- simulation

## Main Components

- `services/dataset-pipeline` — converts raw datasets to unified YOLO format
- `services/cv-inference` — training, inference, benchmark, and export scripts
- `services/api` — FastAPI backend
- `apps/gcs-dashboard` — web dashboard
- `blockchain` — audit/event ledger
- `infrastructure` — Docker Compose and Kubernetes files
- `docs` — setup and project documentation
